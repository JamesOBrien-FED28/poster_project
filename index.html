@Hyper Island <Stockholm Campus>

1200>1800 :: Fri 26.10.30

Send name and class to hackathon@hyperisland.se to enter.

Entrants will have 4 hours to create a website using only HTML and CSS.

Each website will be judged on a number of factors with prizes awarded for a number of categories.

Hackathon is open to all current Hyper Island students.

Prizes for:

  • Most creative use of HTML/CSS
  • Best looking website
  • Best responsive design
  • Best UI/UX
  • Best accessibility
  • Funniest website
